SCENARIO ENGINE

Macro Scenario-Simulation System

CONSTRAINT: a single point forecast is a liability when a macro call is genuinely contested across several paths.

Reads official central-bank minutes, verifies the facts that matter, then drives an interactive engine: five adjustable macro assumptions reweight probability-weighted scenarios in real time, each carrying its own forward narrative. Those scenarios feed a strategy plan built in three layers — a directional base case, contingency-triggered hedges, and a scenario-neutral carry backbone — so the plan stays live across every branch, not just the comfortable one.

→ operational
PROBABILITY LATTICE

Weave — prediction-market probability lattice

CONSTRAINT: correlated outcomes must be priced coherently, not as separate markets.

Built a probability lattice that prices multiple macro outcomes together in one joint distribution, so a correlated question like "both hikes happen" gets one exact price instead of an interval you can only bound. Engineering focus was settlement integrity and determinism: a versioned resolution commons with terminal outcomes, and a state model that is rebuilt deterministically from a compact commit log so it can be reconstructed exactly at any time. A regression suite asserts the pricing and settlement invariants, and anything that breaks them fails the build.

→ prototyped
OPEN-SOURCE PORTFOLIO

Team6-kit

CONSTRAINT: agent teams must run as governed operations, not ad-hoc chat.

ASKA's open-core operating layer for disciplined multi-agent work — role lanes, orchestration choreography, local preprocessing, governance and phase gates, durable state, provenance, and a generator that assembles a configured team from one parameter file. An open-source ASKA portfolio project, not a client case study. Kits layer Apache-2.0.

Both. We have operated data centres and mining facilities as running businesses, and we advise on operations. Engagement scope is agreed up front for each project.

Founders raising capital, companies commissioning infrastructure, and operators restructuring their finances or their holdings.
